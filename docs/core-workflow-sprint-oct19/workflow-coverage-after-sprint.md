## Cross-cutting
- **Client isolation**: every new loader uses `creativeScope(user)`; every new command goes through `authorize()`; tests cover another client (`CLIENT_B`) on each new command and the real-DB check confirms `getLifecycle` returns null for the other client.
- **Draft privacy**: `getLifecycle`, `getScanHistory` and the impact loader exclude DRAFT creatives for TEAM; scans cannot exist for drafts (only submitted rounds are scannable).
- **History**: no new command updates or deletes an existing row; the migration has no DROP/ALTER TYPE/UPDATE; FKs to rule versions, users and creative versions are RESTRICT.
- **No fake approvals**: "Approved" never appears unqualified; the basis (client-reported / team-checked) is stored on every external row and shown next to it.
