What changed

AreaChange
StageThe creative is the largest element: warm-grey stage, true aspect ratio, a version switcher (V1…Vn) and a context badge (round and how it ended). Links keep it shareable: ?v= selects a version, ?compare= turns on comparison.
CompareSplits the stage into the earlier and the selected version, each labelled with its round and outcome, upload details and notes. "Compared with" picks the earlier side. Two columns on every width; rows align across both sides.
Next actionOne block per role and status: Start review; Request changes / Complete review (as expandable forms, the right one highlighted); Waiting on the client; Submit; Your changes needed with the checklist and Resubmit; outcome with the disclaimer.
TabsFindings, Evidence and History. Findings opens first whenever findings need action. Panels stay mounted, so drafts survive tab switches. Arrow keys, Home and End move between tabs.
FindingsFor clients: "Why it matters" and "What you need to do · change the creative and upload a new version" (and similar plain wording), plus "Still needed before you resubmit". For the team: the same card with Edit / Dismiss on drafts and Resolve / Reopen / Withdraw on responses.
EvidenceEach item in its own panel: type, "Submitted with round n" or "Not yet submitted", file chip (download or view), link, supported findings, "Withdrawn by … · date".
HistoryOne chronological ledger: uploads, (re)submissions with notes, decisions with summaries, responses, resolve / reopen / withdraw notes, evidence added or withdrawn.
ResponsiveTwo columns from 1280 px; below that the order is stage, next action and tabs, then upload and details (the same order in the page source, so keyboard and screen-reader order match).
PrivacyA client's private work (evidence, revised versions) no longer moves the submission's "Updated" time; the team's header shows the last submission time. In the browser, the team's page contained none of Alex's unsubmitted response.
RobustnessThe sidebar's queue count can no longer break a page when one database query times out.
